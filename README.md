# PTElove 

A PTE study app that I am building manually, one feature at a time. 

## Current stage 

Repo setup and screen design. 

## First learning flow 

Study a small vocab book for PTE RS and RFD preparation. See a word and its pronunciation guide (UK), listen to the word, and move ot the next entry. 

## First feature 

- One PTE vocab book. 
- Word and pronunciation display. 
- Listen control. 
- Previous and Next controls. 
- Current item position. 

## Planned extension 

Vocab Typing Practice will reuse the same wordbook for listening and answer checking. 

## Project organization 

Keep practice screens, wordbook loading, audio and study data separate. Add new modules step by step. 

## Running the app 

Run instruction will be added with the feature implementation.
